# 🔌 Специфікація деталей (BOM) та Розпіновка (Pinout)

Розробник: **Чабан** (IoT / Hardware Engineer)  
Проєкт: **Макет паркомісця A-01 (ESP32 + HC-SR04 + RGB LED)**

---

## 1. Таблиця з'єднань (Pinout Table)

| Компонент | Пін компонента | Пін на платі ESP32 | Призначення / Опис |
|---|---|---|---|
| **HC-SR04 (Датчик відстані)** | `VCC` | `5V / VIN` | Живлення датчика 5 Вольт |
| | `GND` | `GND` | Спільна земля |
| | `TRIG` | `GPIO 5` | Вихідний сигнал запуску імпульсу (Trigger) |
| | `ECHO` | `GPIO 18` | Вхідний сигнал повернення луни (Echo) |
| **RGB Світлодіод (Спільний катод)** | `Катод (-)` | `GND` | Спільний мінус через землю |
| | `Анод R (Червоний)` | `GPIO 19` | Керування червоним кольором (через 220 Ом) |
| | `Анод G (Зелений)` | `GPIO 21` | Керування зеленим кольором (через 220 Ом) |
| | `Анод B (Синій)` | `GPIO 22` | Керування синім кольором (через 220 Ом) |

---

## 2. Специфікація деталей (Bill of Materials — BOM)

1. **Мікроконтролер:** ESP32 NodeMCU DevKit v4 (з вбудованим Wi-Fi модулем) — 1 шт.
2. **Датчик присутності:** Ультразвуковий далекомір HC-SR04 (2–400 см) — 1 шт.
3. **Індикатор стану:** Триколірний RGB LED 5 мм (спільний катод) — 1 шт.
4. **Резистори:** 220 Ом (струмообмежувальні для діода) — 3 шт.
5. **Макетна плата:** Безпаєчна Breadboard (400 або 830 точок) — 1 шт.
6. **З'єднувальні дроти:** Перемички типу Dupont (тато-тато / тато-мама) — 8–10 шт.
7. **Кабель живлення:** Micro-USB для прошивки та живлення від ПК/павербанка — 1 шт.
