# 📄 Celtics Parking System — Documentation & Project Management

## 📊 Файли:
* [`Celtics_Smart_Parking_System_Tasks.xlsx`](Celtics_Smart_Parking_System_Tasks.xlsx) — офіційний інтерактивний беклог завдань команди «Селтікс» (створений за допомогою GridCraft).

### Аркуші в Excel-файлі:
1. **«ЧАС»** — збережені оцінки PERT для Савчука, Чабана, Андрущенка.
2. **«План завдань та Епіки»** — беклог завдань, статусів та дедлайнів.
3. **«Епіки та User-персони»** — прив'язка 3 епіків до 3 персон (B2C, B2B, Dev) та 10 User Stories.
4. **«Специфікація та Архітектура»** — технічний опис рівнів системи.
5. **«Інструкція до шаблону»** — підказки щодо роботи з розумними таблицями.
