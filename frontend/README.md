# 🎨 Celtics Parking System — Frontend & UI

Розробник: **Андрущенко** (UI/UX / Frontend Engineer)

## 📱 Створені екрани:
1. [`index.html`](index.html) — Клієнтська інтерактивна 2D-карта водія за QR-кодом (Zero-App) із функціоналом **Find My Car**.
2. [`led_board.html`](led_board.html) — Віртуальний дублер в'їзного світлодіодного LED-табло зі статусом **FULL**.
3. [`dashboard.html`](dashboard.html) — Аналітична панель операційного директора ТЦ з живими показниками та алертом **Unauthorized Parking**.
4. [`css/style.css`](css/style.css) — Стилі, дизайн-система Celtics (зелений `#22C55E`, червоний `#EF4444`, синій `#3B82F6`) та анімації.
5. [`js/map.js`](js/map.js) — Логіка запиту до бекенду (`GET /api/v1/map`) та підсвічування маршруту до авто.

## 🚀 Як відкрити та переглянути:
* Можна просто відкрити будь-який HTML-файл подвійним кліком у браузері Chrome / Edge!
* Для перевірки роботи з бекендом Савчука переконайтеся, що бекенд запущено на порті `8000`.
