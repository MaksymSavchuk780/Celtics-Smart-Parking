# 🚗 Celtics Parking System — Python Traffic & Scenario Simulator

Розробник: **Савчук** / команда «Селтікс» (US 3.5 & US 3.6)

## 🎯 Призначення:
Імітація потоку українських автомобілів, бінарних сигналів ультразвукових датчиків та запуск 4 демо-сценаріїв для наочного захисту проєкту перед комісією без використання 50 фізичних плат ESP32.

## 🚀 Як запустити демо для комісії:
1. Запустіть бекенд у сусідній вкладці (`uvicorn app.main:app --reload`).
2. Запустіть скрипт сценаріїв:
   ```bash
   python scenarios.py
   ```
3. Сценарій №4 («Порушник на броні») наочно демонструє ключову бізнес-фічу: заїзд авто `KA 7788 OO` на синє місце `A-18` ➔ автоматичне нарахування штрафу +500 грн на талон ➔ спливаючий алерт у B2B-дашборді директора ТЦ.
